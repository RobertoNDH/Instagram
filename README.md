# InstaNDH 📸

¡Bienvenido a **InstaNDH**! Esta es una red social construida desde cero inspirada en las funcionalidades clave y el diseño de la plataforma original de Instagram.

El objetivo de este proyecto es ofrecer una experiencia moderna, fluida y visualmente inmersiva. Cuenta con una arquitectura *responsive* que se adapta inteligentemente: si accedes desde un ordenador verás una barra lateral completa, y si entras desde tu móvil, automáticamente cambiará a la clásica barra de navegación inferior tocable.

---

## ✨ Características Principales
* **Autenticación Completa:** Registro e inicio de sesión moderno y seguro para usuarios.
* **Sistema de Seguidores:** Sigue a tus amigos y descubre a otras personas en la sección "Explorar".
* **Publicaciones e Interacciones:** Sube tus fotos, dale a "Me gusta" a las publicaciones de la comunidad y deja comentarios.
* **Diseño 100% Adaptativo:** Interfaz que se ajusta a móviles y ordenadores como una App nativa real.
* **Modo Oscuro Integrado:** Disfruta navegando tanto en formato claro como en formato oscuro directamente desde el menú.

---

## 🛠️ Herramientas y Lenguajes Utilizados
Para darle vida a InstaNDH se han utilizado las siguientes tecnologías:
- **Backend:** [Python](https://www.python.org/) y [Django](https://www.djangoproject.com/) (El motor y la lógica del servidor).
- **Frontend:** HTML5, CSS Nativo y toques de JavaScript para las interacciones (como los "Me gusta" instantáneos).
- **Estilos:** Flexbox y utilidades modernas para replicar un diseño Premium sin necesidad de dependencias raras.
- **Base de Datos:** SQLite (Perfecta para probar el proyecto en tu propio entorno local).
